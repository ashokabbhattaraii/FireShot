## Design Notes

- Use Free Fire characters/assets as reference
- Nepal-themed elements (flag colors, Himalayan backdrop) for branding
- Include mode name text overlay (bold, readable)
- Recommended sizes: Thumbnail `400x250`, Banner `1200x400`
- Keep consistent color scheme: 🔥 Orange / Red / Dark background
